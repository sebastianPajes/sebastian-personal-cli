Sebastian Personal CLI

Privacy policy

Effective September 26, 2026.

Purpose and data access

Sebastian Personal CLI is a personal OAuth integration used by its owner with the local gog command-line tool. Google account identity is used to select the intended account. When Gmail access is authorized, the tool can retrieve messages, headers, attachments, labels, and other information available under Gmail read permission, and send messages under Gmail send permission. When authorized, read-only Drive access retrieves file metadata and contents, read-only Google Docs access retrieves document contents, and read-only Calendar access retrieves calendar and event details. Access is used to carry out the owner's requests.

Storage and processing

OAuth credentials and refresh tokens are stored in the owner's macOS Keychain. Command results are processed on the owner's computer. The owner may save requested outputs to local files and controls their retention and deletion. This static documentation website does not receive Google account data or authentication tokens.

Use with other tools

The owner may invoke the CLI through an AI assistant or another local tool. Results deliberately supplied to that tool may then be processed by the tool's provider under its own privacy policy and the owner's settings. Sending email shares the requested message and attachments with the intended recipients through Gmail. The integration does not sell Google user data, use it for advertising, or use it to train generalized AI models.

Sebastian Personal CLI's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including its Limited Use requirements.

Revocation and deletion

The owner can revoke access at any time in Google Account connections, remove stored credentials through the CLI, and delete saved local output files. Revoking this integration does not delete messages from Gmail. Google account data remains subject to Google's own account controls.

This website

These pages contain no analytics scripts, advertising, cookies set by the application, or data collection forms. GitHub Pages hosts the site and may process technical request information under GitHub's privacy statement.

Contact

Contact the maintainer through the project issue tracker. Do not post credentials, private messages, or other sensitive information in public issues.
